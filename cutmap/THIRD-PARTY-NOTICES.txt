CutMap 第三方组件与数据来源说明
==================================================

本软件封装了以下第三方组件与数据。分发本软件或其产物时，请一并保留本说明。

--------------------------------------------------
1. GDAL — 地理数据抽象库
--------------------------------------------------
用途：DEM 拼接、裁剪、重采样，以及产物元数据的实测读取。
许可：MIT License
版权：Copyright (c) 2000-2026, Frank Warmerdam, Even Rouault, and contributors
来源：https://gdal.org

本软件通过 NuGet 包 MaxRev.Gdal.Core 与 MaxRev.Gdal.WindowsRuntime.Minimal
（版本 3.13.3.580）使用 GDAL。这两个包内含 GDAL 3.13.3 的原生库及其支撑数据
（GDAL_DATA / PROJ_DATA）。

GDAL 随附的 PROJ 库：
  用途：坐标系定义与转换
  许可：MIT License（X/MIT）
  来源：https://proj.org

GDAL 可能以插件形式启用的其他可选库（GEOS、SQLite、libtiff、libjpeg、
libpng、zlib 等）各自遵循其原有许可，详见 GDAL 发行包内的 LICENSE.TXT。

--------------------------------------------------
2. cesium-terrain-builder (CTB) — 地形瓦片切片器
--------------------------------------------------
用途：把 GeoTIFF 切成 Cesium 地形瓦片（heightmap-1.0 格式）。
许可：MIT License
版权：Copyright (c) 2014, Dan Brough
来源：https://github.com/geo-data/cesium-terrain-builder

本软件以**子进程**方式调用 ctb-tile.exe，不修改也不链接其代码。
CTB 0.4.1 由本项目自行编译，随包分发于 ctb/ 目录。

--------------------------------------------------
3. Copernicus DEM GLO-30 — 高程数据
--------------------------------------------------
用途：产出的地形瓦片的原始高程来源（用户下载的分幅）。
许可：Copernicus DEM 由 ESA 与 European Commission 提供，免费使用，
      分发时**必须注明出处**。
出处声明建议写法：
  "Contains modified Copernicus DEM GLO-30 data (2026),
   © ESA / European Commission"
来源：https://copernicus-dem-30m.s3.amazonaws.com

注意：本软件**不重新分发** Copernicus 数据本身；数据由用户按自己配置的
下载源获取。使用官方源时，下载的是上述公开数据。

--------------------------------------------------
4. 行政区划边界数据
--------------------------------------------------
用途：按行政区划边界裁剪，以及随产物分发界线（FR-14 / FR-15）。
来源：**DataV.GeoAtlas**（阿里云 DataV 公开行政区划服务）
      https://geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json
      https://datav.aliyun.com/portal/school/atlas/area_selector
随软件或产物分发时请注明上述来源。

> **与 PRD §6 的出入（需注意）**：PRD 记录的原始数据源是**天地图**
> （国家地理信息公共服务平台）。本项目改用免密的 DataV 公开接口，
> 原因不是"没试过"——天地图的 Key 已实际申请并实测，卡在它自己的
> 权限类型判定上：
>
>   控制台显示应用类型为「服务器端」，但 API 网关对该 Key 一律返回
>   `{"code":301013,"msg":"权限类型错误","resolve":"Key权限类型为:浏览器端"}`。
>   给服务端用的 Key 被网关归为浏览器端，脚本无法调用。已排除请求格式
>   （GET / POST 表单 / POST JSON 结果相同）与下发延迟（隔时重试仍同）。
>
> 详细过程见 resources/天地图-Key申请教程.md。若将来拿到可用的服务器端
> Key，脚本已支持 `--source tianditu`，抓一遍即可换源。
>
> 两者来源不同，**署名要求也不同** —— 请按实际使用的 DataV 署名，
> 不要照抄 PRD 里的天地图。

数据由 resources/fetch_boundaries.py 抓取与合并，产出：
      中国_省.geojson / 中国_市.geojson / 中国_县.geojson
      坐标系 CGCS2000 经纬度（EPSG:4490），与 WGS84 DEM 兼容、无 GCJ-02 偏移。
      字段 name（名称）+ gb（含 156 前缀的行政区划代码）。

数据精度与适用性由数据提供方决定，本软件只负责读取与使用。

--------------------------------------------------
5. .NET 运行时（自包含分发时内含）
--------------------------------------------------
用途：本软件自身的运行环境。
许可：MIT License
来源：https://github.com/dotnet/runtime

自包含发布（SelfContained）会把 .NET 运行时随程序一起分发，
用户机器无需另行安装。
